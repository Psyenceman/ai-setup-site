Privacy Policy

Last updated: November 8, 2026

AI Setup Sync is a private utility intended for use by its owner to maintain project documentation in Google Drive using information from selected GitHub repositories. It is not a public-facing service.

Information accessed

After the owner's authorization, the application is intended to access only Google Drive files explicitly authorized for use by the application. The requested Google OAuth scope is https://www.googleapis.com/auth/drive.file. It does not by itself grant access to every existing Drive file.

Purpose and processing

Authorized Markdown documents may be read, compared with repository documentation, and updated in place. The utility may process document contents, file identifiers, timestamps, and technical execution logs to carry out and verify synchronization. No automatic synchronization is active until setup and authorization are completed.

Storage and service providers

GitHub Actions is the intended execution environment. OAuth credentials, when configured, will be held as protected GitHub repository secrets rather than committed to source code. Google Drive remains the storage location of the original Markdown documents. GitHub and Google process information according to their respective service terms and privacy notices.

Sharing and retention

The utility is not intended to sell personal information or share Drive document contents with advertisers. Operational logs may be retained under the configured GitHub Actions retention policy. The owner controls the original files and can delete or edit them directly in Google Drive.

Access and revocation

The owner can revoke the app's Google access from their Google Account's third-party connections settings. Revocation stops future authorized access; it does not automatically remove previously generated logs.

Contact

For questions about this private utility, contact its operator through the support email displayed on the Google OAuth consent screen.
